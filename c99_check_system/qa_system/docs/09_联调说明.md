
```powershell

```

```powershell

  -Method POST -ContentType "application/json" `
  -Body '{"question":"6.5.2.2 函数调用的规则"}'
```

## 五、常见问题

| 现象 | 处理 |
|------|------|
| `faiss_ready=false` | 运行 `python scripts/build_faiss_index.py` |
| 生成报 LLM 错误 | 检查 `.env` 中 `LLM_*` / `USE_OLLAMA` |
| PowerShell curl 报 Headers 错误 | 用 `Invoke-RestMethod` 或 `curl.exe` |
| 多轮无历史 | 打开 `ENABLE_MYSQL` 并保证库连通 |
| 前端连不上 | 确认后端 `--host 0.0.0.0` 与防火墙 |
