# 数据与存储设计

本系统知识库以 **C99 条款数据 + FAISS 向量索引** 为主；MySQL 仅可选用于**会话历史**。

---

## 1. C99 条款数据（主知识库）

目录：`qa_system/data_c99/`（配置项 `LAW_DATA_DIR`）

| 文件 | 说明 |
|------|------|
| `chunks.jsonl` | 按条款切分的检索块（**建索引主文件**，581 条） |
| `faiss/` | 向量索引 + 元数据 |

### 1.1 chunks.jsonl（每行一条）

```json
{
  "id": "c99-6.5.2.2",
  "text": "Function calls\nConstraints:\n[1] ...",
  "law_name": "ISO/IEC 9899:1999 (C99)",
  "article": "6.5.2.2",
  "status": null,
  "source_url": "https://port70.net/~nsz/c/c99/n1256.html#6.5.2.2",
  "source_file": "n1256_c99_tc3.html"
}
```

### 1.2 字段映射（清洗 → 后端 meta）

| 清洗侧 | FAISS meta / 内部 |
|--------|-------------------|
| `id` | `chunk_id` |
| `law_name` | `law_name`（标准名） |
| `article` | `article`（条款编号） |
| `text` | `text` |
| `source_url` | `source` |
| `status` | `status` |
| `source_file` | `source_file` |

加载时过滤纯标题父节等无效块，详见 `app/retrieval/legal_data_loader.py`。

---

## 2. FAISS 索引

目录：`qa_system/data_c99/faiss/`（`FAISS_INDEX_DIR`）

| 文件 | 说明 |
|------|------|
| `index.faiss` | 向量索引 |
| `meta.json` | 与向量一一对应的条款元数据 |
| `embed_info.json` | embedding 后端、维度、条数 |

构建命令：

```powershell
cd qa_system
python scripts/build_faiss_index.py
```

---

## 3. MySQL（可选 · 会话）

当 `ENABLE_MYSQL=on` 时，用于：

- `ai_history`：多轮对话与流式续写
- `ai_feedback`：用户反馈

**不存储 C99 条款正文。** 库名见 `.env`。

### ai_history 主要字段

| 字段 | 说明 |
|------|------|
| `session_id` | 会话 UUID |
| `role` | user / assistant / … |
| `content` | 正文 |
| `intent` | 意图标签 |
| `sources` | JSON 溯源 |
| `sent_offset` / `streaming_done` | 流式续写 |

表结构由 `SessionManager.ensure_table()` 自动创建/补齐。
