# 系统架构

## 1. 整体架构

本系统为 **C99 测试代码生成后端**，基于 FAISS RAG + 多 Agent + 大语言模型。

```text
┌─────────────────────────────────────────────────────┐
│              前端 chat-web / 其他调用方               │
│           HTTP REST  +  WebSocket 流式               │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│                 main.py (FastAPI :8000)              │
│   qa_router  ·  ws_router  ·  admin_router  · /health│
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│              SessionManager / QAEngine               │
│                                                      │
│   QA Agent (main_agent)                              │
│        │                                             │
│        ├─► Retriever Agent ──► FAISS Tool            │
│        │                         │                   │
│        └─► Summarizer Agent ◄────┘                   │
│                 │                                    │
│                 ▼                                    │
│           LLM 流式生成 C 测试代码                     │
└──────────────────────┬──────────────────────────────┘
                       │
         ┌─────────────┴─────────────┐
         ▼                           ▼
┌─────────────────┐         ┌─────────────────┐
│ data_c99/faiss/ │         │ MySQL（可选）     │
│ 向量索引+meta   │         │ ai_history 会话  │
└─────────────────┘         └─────────────────┘
         ▲
         │ build_faiss_index.py
┌────────┴────────┐
│ data_c99/       │
│ chunks.jsonl    │
└─────────────────┘
```

---

## 2. 技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| Web | FastAPI | REST + WebSocket + Swagger |
| 检索 | FAISS | `IndexFlatIP` 语义检索 |
| 向量化 | sentence-transformers / hashing 回退 | Windows 长路径下可回退 |
| Agent | 自研流水线 | 三 Agent 协作 |
| LLM | OpenAI 兼容 / DeepSeek | `.env` 配置 |
| 会话库 | MySQL（可选） | 仅 `ai_history`，非知识库 |

---

## 3. 配置要点（`.env`）

```env
LAW_DATA_DIR=./data_c99
FAISS_INDEX_DIR=./data_c99/faiss
EMBEDDING_MODEL=sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
RAG_TOP_K=5

ENABLE_MYSQL=off          # on 时启用会话持久化
ENABLE_NEO4J=off          # 遗留，默认关闭

USE_OLLAMA=off
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=...
LLM_MODEL_NAME=deepseek-chat
```

---

## 4. 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| Retriever Agent | `app/agents/retriever_agent.py` | 编号精确匹配 / 关键词映射 / FAISS 检索 |
| Summarizer Agent | `app/agents/summarizer_agent.py` | RAG context + sources |
| QA Agent | `app/agents/main_agent.py` | 流式生成 C 测试代码 |
| 兼容层 | `app/agents/graph_agent.py` | 调用检索 + 总结，兼容旧入口 |
| FAISS | `app/retrieval/faiss_retriever.py` | 索引加载与 search |
| 数据加载 | `app/retrieval/legal_data_loader.py` | 解析 C99 条款 JSONL |
| 会话 | `app/core/session_manager.py` | 历史 / 流式 / 反馈 |

---

## 5. 数据流（一次 ask）

1. 接口层收题 → SessionManager / QAEngine
2. Retriever：编号精确匹配 → 关键词映射 → `search` top-k hits
3. Summarizer：压缩为 `rag_context`，生成 `sources`
4. QA：system prompt 约束「依据条款生成、标注验证点」→ 流式 / 非流式返回
5. `done` / `AskResponse` 携带 `has_kg_facts`、`sources`
