# 成果与工作留痕

本项目把 C99 条款 → 生成编译器符合性测试代码，并评估生成代码对条款的覆盖率。此目录存放「成果」与「工作留痕」，与源码（`../legal_qa_system/`）分开。

## 结构

- `coverage/` —— 覆盖率评估成果（热力图、results.json、生成的测试代码），详见其 README
- `data_c99/` —— 数据留痕副本（C99 原文、切分脚本、chunks、FAISS 索引），是 `../legal_qa_system/qa_system/data_c99/` 的**快照**，供答辩汇报溯源；后端运行时读的是源码目录里的那份，互不影响
